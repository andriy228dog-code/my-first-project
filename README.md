# ПЗ 10. Робота з GitHub
Навчальний репозиторій для практичної роботи з GitHub.
# Мета
Опанувати основні інструменти GitHub: репозиторії, гілки, commit, Pull Request та merge.
# Виконані кроки

- створено репозиторій;

- створено гілку edit-readme-file;

- відредаговано файл README.md;

- підготовлено Pull Request для злиття змін у гілку main.
